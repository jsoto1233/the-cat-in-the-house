# Cat in the House — Project Plan

**Team:** Ayman Ali, Jose Soldevilla, Vincent Hua

## Background

Cat in the House is a real-time multiplayer horror escape game where players work
together to collect clues, solve puzzles, and escape both the house and a dynamically
designed cat. The project targets cooperative multiplayer horror — an underserved
space compared to single-player horror — while building our skills in React, Phaser,
Node, Socket.io, and Vite.

## Aims & Objectives

- Responsive frontend in React; core mechanics in Phaser; multiplayer sync via Node.js.
- Real-time multiplayer with Socket.io so players connect and interact seamlessly.
- Puzzle and clue-collection systems with shared multiplayer progression.
- Continuously updated game state (objectives + timer).

## Tech Stack

- **React + Vite** — Menus, lobby, and HUD (frontend / UI)
- **Phaser.js** — Game world and entities
- **Node.js** — Server runtime
- **Socket.io** — Real-time communication between players and server
- **Tools** — VS Code, GitHub
